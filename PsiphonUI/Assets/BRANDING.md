# Se7en Pro branding placeholders

Replace these files before producing a public release:

- `app.ico` — Windows executable icon.
- `app-icon.png` — in-app logo placeholder.
- `tray-connected.ico`, `tray-connecting.ico`, `tray-disconnected.ico` — tray state icons.

Keep filenames unchanged so the WPF resources and project file continue to resolve them.
